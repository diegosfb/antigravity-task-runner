# Demand and bench schemas

## Demand
- demand_id
- project / workstream
- role / profile
- primary_skill / technology
- secondary_skills
- seniority
- quantity
- geo / country / region
- requested_start_date
- duration / end_date
- allocation_percent
- mandatory_geo
- mandatory_seniority
- timezone / language
- priority
- notes / constraints

## Bench / internal supply
- resource_id (prefer non-sensitive identifier)
- role
- primary_skill
- secondary_skills
- seniority
- current_geo
- timezone
- language if job-relevant and supplied
- available_from
- available_allocation_percent
- recent_experience / proficiency when supplied
- mobility / geo flexibility when supplied
- notes

Do not use protected or sensitive personal characteristics in matching.
