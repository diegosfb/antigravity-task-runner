# Data visualization for pitch decks

Start with the relationship the audience must understand.

| Relationship | Preferred visual |
|---|---|
| Change over time | Line chart |
| Compare categories | Sorted bar chart |
| Composition | Stacked bar; donut only for a few simple parts |
| Conversion stages | Funnel or staged bars |
| Drivers from start to finish | Waterfall |
| Relationship or positioning | Scatter plot, with defensible axes |
| One decisive metric | Large number plus context |

Use a claim as the chart title. Label units and time periods, cite the data source, distinguish actuals from projections, and highlight only the evidence supporting the claim. Prefer direct labels to legends.

Avoid 3D effects, truncated axes that exaggerate differences, dual axes without compelling need, excessive precision, decorative charts, unexplained market quadrants, and red/green-only encoding. Keep sufficient contrast and add shape or labels so meaning does not depend on color.

When data is incomplete, show the gap as a placeholder or omit the chart. Never fabricate a plausible-looking series.
