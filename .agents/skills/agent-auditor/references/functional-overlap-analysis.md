# Functional overlap analysis

Compare candidate agents across trigger, responsibility, lifecycle, inputs, outputs, authority, execution, callers, and unique value. Similarity is candidate generation, not a decision.

- **MERGE** when responsibilities, lifecycle, authority, and outputs substantially coincide.
- **KEEP + SHARPEN** when triggers collide but ownership or output contracts differ.
- **KEEP SPECIALIZED** when shared vocabulary reflects adjacent expert domains.
- **DEMOTE** when the capability is useful only as an internal helper.
- **RETIRE** when another maintained agent or baseline behavior supersedes it.
- **REMOVE DUPLICATE** only for redundant copies with an identified canonical source.

Read both definitions and trace repository references before deciding. Every consolidation or retirement recommendation must name callers, unique resources, configuration, approvals, and artifacts that must be migrated or intentionally retired.
