## Codex

In this project, “Agent Monitor” refers to a local dashboard that runs alongside Claude, Codex, or
OpenCode and shows:

- Current model and reasoning effort
- Token/context-window usage
- Loaded agents, skills, and MCP resources
- Conversation/session output
- Context-pressure warnings

“Agent Monitor Claude” and “Agent Monitor Codex” in `TODO.txt` appear to be planned launcher actions
for opening the monitor with the corresponding coding agent. It is privacy-focused and reads local
session metadata without retaining prompts, reasoning, credentials, or tool payloads.

## You

how is it invoked ?

## Codex

From the plugin directory, install it once:

```bash
cd plugins/agent-usage-monitor
python3 scripts/agent-usage-monitor.py install
```

Then launch an agent with the monitor sidebar:

```bash
agent-usage-monitor launch claude
agent-usage-monitor launch codex
agent-usage-monitor launch opencode
```

Arguments are forwarded to the agent CLI:

```bash
agent-usage-monitor launch claude --model sonnet
```

Running `claude` or `codex` normally shows only the compact status line.
