# BA Agent exposes two optional context inputs

Kept Existing Specifications optional because the BA Agent consumes it only when resuming or revising requirements. Exposed Supporting Evidence as the second optional visible input because the BA contract uses reviewed research and meeting context to clarify the mandatory Approved PRD. Kept the specialized alternative input contract hidden.
