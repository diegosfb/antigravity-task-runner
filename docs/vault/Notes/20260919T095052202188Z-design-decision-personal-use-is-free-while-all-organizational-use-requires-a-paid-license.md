# Personal use is free while all organizational use requires a paid license

The license permits natural persons to use and modify the work privately on their own behalf. Employer, company, nonprofit, educational, government, development, testing, CI, staging, and production use require a separate paid commercial license; redistribution is not permitted. California law governs. The text remains a draft requiring qualified counsel review, and earlier grants remain unaffected.
