# Project Planner consumes optional UX Design Package

The Project Planner Agent now requires the Specifications Directory and Architecture Folder, and optionally consumes the Design Package and Existing Backlog. Its page uses orange required borders, gray optional borders, a yellow dotted input group, and a green Task Backlog output. Defaults are docs/specs, docs/architecture, docs/design, and docs/backlog.
