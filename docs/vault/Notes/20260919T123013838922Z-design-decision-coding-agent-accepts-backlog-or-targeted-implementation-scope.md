# Coding Agent accepts backlog or targeted implementation scope

The Coding Agent screen now accepts either the backlog or one user story/specification. A targeted source suppresses backlog in the generated prompt. Existing repository code and tests remain implicit inputs, and the diagram removes the misleading src Tests box while retaining the green src source-code output.
