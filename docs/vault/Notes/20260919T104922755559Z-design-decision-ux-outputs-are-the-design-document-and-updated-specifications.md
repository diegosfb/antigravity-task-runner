# UX outputs are the design document and updated specifications

Removed the Experience Disposition and separate planning handoff outputs. For user-facing work, the UX Agent writes docs/design/design.md and embeds approved interaction, state, responsive, accessibility, acceptance-criteria, and design-reference details into affected docs/specs files. For non-user-facing work, the design document remains absent or empty and specifications remain unchanged. The Project Planner now consumes the UX-enriched requirements stream instead of a separate design stream.
