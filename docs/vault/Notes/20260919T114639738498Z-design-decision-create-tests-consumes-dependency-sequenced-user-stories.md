# Create Tests consumes dependency-sequenced user stories

The Create Tests page now uses one required Sequenced User Stories by Dependencies input, defaulting to docs/backlog, with an orange border and yellow dotted input group. The Test Suite output remains green. The canonical Test Agent keeps its verifier inputs but now explicitly treats sequenced user stories and their dependency context as governing context.
