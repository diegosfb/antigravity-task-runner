## Description
After Set Feature Flag for changes add a collapsable/expandable item called ADLC Agents. Inside of it it should have ADLC Agents-> 

Product Agent
BA Agent
UX Agent
Architect Agent
Architecture Review Agent
Project Planer Agent
Test Agent 
Coding Agent
Code Review Agent
Documentation Agent
Spec Validation Agent
Deployment Agent
SDLC Orchestrator Agent

Agents from .agents/agents

Each of this when clicked should launch a new page where you can select the harness and model, define the input files required for that agent and a cancel or execute button. Upon execute it should launch a terminal using the harness and model selected and call the agent passing the input artifacts defined by the user
